# Global Energy Monitor: Global Coal Mine Tracker

Put the downloaded workbook here as `Global-Coal-Mine-Tracker.xlsx` (free; request it through the form on
globalenergymonitor.org). Only `scripts/data/v2/build_v2.py` reads it.

- Release used: <fill in, e.g. "April 2026 release">
- Downloaded on: <date>
- Licence: <paste the licence line from GEM's terms page before publishing>
- Used for: mine coordinates, and GEM's mine-level methane estimate (shown as a comparison, not as the default input)

GEM's estimate method: annual CH4 (million m³) = production × gas content at mining depth × emission factor
(underground 1.6, surface 1.5). See https://gem.wiki/Estimating_methane_emissions_from_coal_mines
